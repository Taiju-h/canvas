# Canvas Notes / メモ整理の運用

## 目的・合意した操作

- Appleのメモのように、左は過去のメモ、右は文章中心の編集。
- 左の一覧は折りたたみ可能。開閉状態を端末に記憶し、スマホでは引き出し表示。開閉ボタンはメモ帳・お絵かき共通でヘッダー左上の同じ位置に置く。サイドバーの開閉や幅変更で移動させず、開閉状態は矢印と背景で示す。
- 起動時は文字入力。ペンとして認識される入力は文字ツール中でも手書き。指ドラッグは画面移動。
- 文章ブロックはつまみで移動し、右下のつまみで幅変更。文字内のドラッグは文字選択。
- 文章ブロック上から書いた線はブロック移動に追従する。画像は貼り付け・添付から追加可能。
- カテゴリ・タグは固定しない。ユーザーから整理依頼を受けたときに、担当AIが内容を読み、追加・統合・名称変更・グループ再編を判断する。
- 分類ごとの細かな事前確認は不要。元の本文、元の分類、元ID、添付は保持する。
- 常時自動でAIを呼び出す機能ではない。ユーザーの依頼をきっかけに整理する。

## 整理の受け渡し

1. 左メニューの「ページ・フォルダを整理」→「データを取り出す」→「整理用MD・分類JSONを書き出す」を実行する。設定の旧書き出しボタンも使用できる。
2. `Canvas-メモ整理.md` と `Canvas-分類.json` をAIへ渡す。
3. AIはMDを読み、必要に応じて分類を統合・分割・改名する。要点、決定事項、やること等の整理結果は元のメモIDと対応づけてMDに残す。
4. 分類JSONは各メモの `id` と `revision` をそのまま保持し、`category` と `tags` を編集する。
5. 「整理した分類を読み込む」でJSONを選ぶ。本文は変更せず、分類・タグと変更履歴だけを保存する。
6. 分類反映は端末内でも実行できる。読み込み対象を事前検証し、revisionが変わっていたら再度書き出す。未同期の本文は保持し、分類・タグだけを更新する。

分類JSONの形式（IDは架空の例）:

```json
{
  "version": 1,
  "notes": [
    { "id": "00000000000000000000000000000001", "revision": 3, "category": "仕事 / アイデア", "tags": ["UI", "検討中"] }
  ]
}
```

- カテゴリは200文字以内。タグは50個以内、各80文字以内。
- 分類変更履歴は直近100件をメモJSON内に保持。
- 端末の未同期本文もMDの書き出し対象。新規の未同期メモも `local-` IDで分類JSONへ書き出し、オフラインで分類を反映できる。
- MD内の添付リンクはCanvasの認証を必要とする。MDは添付本体のバックアップではない。
- 本文・フォルダ・画像・添付を自分のファイルとして取り出すには、整理ページのZIP保存を使う。保存先、形式、未取得データと容量の制約は `NOTE-DATA-ORGANIZER.md` を参照。
- 個人のメモ本文・JEX・添付・整理結果を公開Gitリポジトリにコミットしない。

## Joplin取り込み

1. Joplinで添付を含めて同期し、すべてのノートをJEXでエクスポート。
2. Canvasの左下「Joplinから取り込む」、または設定からJEXを選択。
3. 件数を確認して「取り込みを開始」。メモの元ID、ノートブック階層、タグ、本文、作成・更新日時、ToDoを保持する。
4. 画像を本文に表示し、PDF・動画・ZIP・Excel・CSV等も添付として保存。再生・表示の可否はブラウザの対応形式による。ファイルの原本はダウンロード可能。
5. 同じ元IDの完了メモは再取り込みでスキップ。中断されたメモは同じJEXで再開する。継続的な双方向同期ではなく一回の移行用。
6. どのメモからも参照されていない添付は「Joplinの未参照添付」に保存する。

JEX全体をサーバーに一括アップロードせず、ブラウザでTARを読み、本文と添付をまず端末へ保存する。通信があるときに添付を1MiBずつ同期する。1添付512MiBまで。巨大JEXでは処理時間がかかるため、取り込み中はページを閉じない。中断後は同じJEXを選び直せる。

## 保存・互換性

- 作業表示は「メモ帳」「お絵かき」「完全作業領域」の3種類。お絵かきは一覧とレイヤー欄を一旦畳み、必要なら再表示できる。メモ帳へ戻ると元の欄を復元する。メモ帳／お絵かきの選択は端末に記憶し、完全作業領域の「戻る」は直前の表示へ戻す。OSの全画面切替とは独立している。
- Gペン・ペン・マーカーに加え、筆圧と入り抜きのある「筆」、縁が柔らかい「エアブラシ」を使える。描画中と保存後は同じ形で表示し、ブラシ・太さ・濃さ・筆圧を線ごとに保持する。消しゴムは手書きの線を消し、原本画像と本文を保持する。表示切替で本文・線・添付・元に戻す履歴を作り直さない。
- レイヤー一覧の上を手前として、ノート・キャンバス・レイアウト・グラフの実際の重なり順へ反映する。未設定時はキャンバスをノートより上に置く。ノート内の画像・表の上にも手書きと描画中の線を表示し、上下の並べ替え・消しゴム・元に戻す・再読み込みでも順序を保つ。
- ノート本文と画像のサイズはCanvas倍率から独立させ、上下スクロールは手書きと共通にする。ノート編集中のペン入力もキャンバスへ保存し、本文HTML・原本画像・添付・分類を変更しない。
- 本文と分類は既存 `canvas_documents.content_json` に保存。新規DBテーブルや既存テーブル変更は不要。
- 添付本体は公開ディレクトリ外 `var/attachments/{document_id}/`。取得・追加は文書所有者の認証が必要。
- `var/attachments` はDBと一緒にバックアップすること。Gitには含めない。
- ローカルIndexedDBはアカウント別に絞り込む。未同期の本文をサーバーの古い本文で上書きしない。
- 競合を自動で上書きせず、端末側の内容を保持し「今の内容を別メモに保存」で回収できる。
- 元のキャンバスの図形・自由線・ラスターレイヤー・画像データを保持。旧テキストは編集可能なブロックへ変換する。
- 旧キャンバスの負の座標は最初にメモ表示へ移行するとき、全体の相対位置を保ったまま正の座標へ移す。
- この版の新規手書きは一定幅の線。消しゴムは線単位。従来の製図・レイヤー編集画面をそのまま再現するものではない。
- ペン種別が端末から通知されない場合は「ペン」ボタンを使う。タッチ端末のソフトキーボードはブラウザの制約によりタップが必要な場合がある。

## 2026-09-29 追加：整理・検索・表示

- 「メモを削除」はゴミ箱へ移動する。本文・添付は保持し、「ゴミ箱」から復元できる。通常の一覧・整理用一括書き出しには含めない。ゴミ箱内の本文は読み取り専用。
- カテゴリは `親 / 子 / 孫` の階層で表示する。親を選ぶと配下も一覧に出る。三角ボタンで枝を折りたためる。
- 「カテゴリを管理」で空のカテゴリ／子カテゴリを作成できる。空カテゴリも利用者ごとにDBで保持する。
- 移動・名前変更は子カテゴリと所属メモをまとめて変更する。自分自身・子カテゴリへの移動や同名への上書きは拒否する。
- タグ変換は指定カテゴリ配下（ゴミ箱内も含む）のメモへタグを付与する。既存タグは保持し、「変換後に対象カテゴリを外す」を外せばカテゴリも残せる。本文・添付・元ノートブックは変更しない。
- カテゴリ一括変更はDBトランザクションとrevision確認で全件成功または全件取消にする。未同期メモ、競合、取り込み途中のメモがある場合は先に解消する。
- 横断検索はタイトル・本文・カテゴリ・タグ・添付ファイル名を対象とする。カテゴリ選択中でも「全カテゴリ横断」なら他カテゴリも検索する。「選択中のカテゴリ・タグ」に切り替えれば絞り込める。空白区切りの複数語はAND、全角／半角・英字の大文字／小文字を同一扱いにする。PDFや画像内のOCR検索は含まない。
- 検索はヘッダの虫眼鏡または Ctrl+Shift+F で呼び出せる。
- ズームは編集ツールとは別の常設バー。20〜400％、100％へ戻す、画面に合わせる、Ctrl＋ホイールに対応する。

## Git反映のユーザー指示

- キャンバス／レイアウトを選ぶと上部に枠（四角形）・丸（楕円）・直線・テキストボックス・画像を表示する。レイアウトでは黒矢印・白矢印も上部から使える。図形は既存のレイアウトレイヤー処理を使い、選択中の同種レイヤーを維持する。
- 左のファイルメニューは右端をマウス・指・ペンで左右にドラッグして幅を変える。端末に幅を記憶し、画面が狭くなれば収まる範囲へ制限する。ダブルクリックまたはつまみを選択してEnterで標準幅へ戻す。左右キーでも調整でき、本文・分類・添付は変更しない。

## スマホの指操作（2026-09-29）

- 「ペン」を選ぶと指で描ける。文字ブロック上も描画でき、文字選択やキーボード起動を抑える。
- 「文字」ではタップで入力、指ドラッグで縦スクロール。「移動」では指で縦横に移動する。「線を消す」も指で選べる。
- ペンデバイスは引き続き文字モード中でも自動的に描画する。
- 描画を開始した指だけを追跡し、別の指の移動・離脱で線を終了しない。
- キーボードやアドレスバーによる高さ変更で倍率を合わせ直さない。初めてメモを開くときと画面幅が変わるときにスマホの初期幅合わせをする。
- キャンバスのスクロール領域は拡縮後のサイズに合わせる。本文サイズの計測や削除でスクロール領域を急に縮めない。

## 2026-10-20 描画と図形の操作

- 右上のプロパティの下にレイヤー一覧、ツールバー右下に「詳細」を置く。開閉してもノート本文・選択書式・Undoを保持する。スマホのレイヤー一覧はツールバーの下に重ねる。
- Canvasはペン、鉛筆、Gペン、筆、マーカー、エアブラシ、消しゴム、投げ縄、移動を使う。図形・文章ボックス・画像配置はレイアウトへ分ける。
- 消しゴムは円形で触れた部分だけ消す。直径スライダー（または `[` / `]` キー）で大きさを変える。隣のプルダウンで「× 線全体を消す」を選べる。Shift＋消しゴムでも2方式を切り替える。ペンの消しゴム側とタッチでも同じ処理を使い、1回のジェスチャーを1回のUndoで戻せる。
- 投げ縄で自由な範囲を囲み、内側をドラッグすると囲んだ部分だけ移動する。選択を複製・削除・解除でき、Deleteで削除、矢印キーで1px移動（Shiftで10px）、EscまたはCtrl/Cmd＋Dで解除する。選択範囲がある間に描く線はその内側へ限定する。
- 部分消去・投げ縄の切り分けは `inkMasks` としてノートJSONへ保存する。元の点列・筆圧・色・添付・分類を変換せずに残す。マスクは線の移動・拡縮・回転に追従し、PNGには選択の点線や消しゴムカーソルを出力しない。
- レイアウトの丸・三角・四角・矢印はボタンで選ぶ。ほかの多角形・星・吹き出し・ハート・各種矢印・直線は「図形プリセット」から選び、ドラッグして配置する。Shift＋ドラッグでプリセットの縦横比を維持する。
- 選択したベクター図形は「プリセットに追加」で名前を付けて登録できる（複数図形は32個まで）。登録図形はこの端末のアカウント別設定へ保存し、別のノートでも再利用できる。文章・添付画像は登録対象にしない。
