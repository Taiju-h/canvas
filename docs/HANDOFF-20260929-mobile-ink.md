- ユーザー依頼: スマホはペンを持っていないためペン選択時は手（指）で書きたい。ページサイズのぐらつきを修正。
- 前回の「指示の後は常にMainマージ」に従い、検証後にmainへ統合。本番デプロイは別。

## 原因と変更

- 指の入力がツール判定前に必ずpanへ分岐していた。文字・移動の場合のみpanとし、ペンでは指も描画へ分岐。
- pointerIdを保持し、別の指のmove/upが進行中の操作へ混入しないよう修正。
- 文字以外のツールでは本文をcontentEditableにしない。ツール切り替え時は文字フォーカスを解除。
- 全resizeイベントで幅合わせしていた処理を、文書変更・画面幅変更時に限定。高さのみの変更では選んだ倍率を維持。
- transform縮小時も元のレイアウト幅がスクロール領域に寄与していたため、明示サイズのラッパー内で絶対配置し領域を制限。
- スクロール領域は表示中のメモについて段階的に拡張し、内容の計測・削除で縮まないようにした。スクロールアンカーも無効化。
- モバイルは安定したビューポート高さと16px以上の入力文字を使用。文字モードの指スクロールは縦に限定し、縦横移動は移動ツールに分離。

## 確認・未確認

ブラウザ自動試験にタッチ描画、複数指、高さ変更時の倍率保持、縮小後のスクロール幅、文字モードの縦スクロールを追加。
変更はフロントエンドのみ。DBスキーマ・本文保存形式の変更なし。
