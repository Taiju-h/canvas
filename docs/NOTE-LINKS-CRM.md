# お気に入り・本文リンク・CRMの関連付け

## 開く操作と編集

- ノート本文・文章ブロックのURLは1クリック／1タップで開く。Ctrl・ダブルクリックは不要。Canvas内のメモへのリンクは同じ画面で開き、外部URLは別タブ（Androidでは既存シェルの外部URL処理）で開く。
- URL以外の本文は、クリックした位置から文字を編集する。リンク文字をドラッグして選択した場合は移動せず、選択を維持する。
- 保存済みの裸のWeb URL、貼り付けたWeb URL、本文の入力を終えてフォーカスを外したWeb URLをリンク表示する。コード・整形済みテキスト内は変換しない。
- 文字を選択、または画像・動画を選択して、ノートのツールバーの「リンク」を押す。右クリックの「リンクを設定・変更」も利用できる。既存リンクの変更・解除も同じ画面で行う。
- 画像・動画には、原本の参照とクリック先のURLを別々に保持する。クリック先の変更・解除で原本を置き換えない。リンク付き動画はクリックで外部ページへ進み、再生は資料の「プレビュー」またはリンクを解除して行う。

## 資料とオフライン

- 「資料」の☆でよく使う資料を固定できる。Web／YouTubeのカード、リンクを設定した画像・動画は1クリックで指定先を開く。「メモを開く」で編集元へ戻れ、画像・動画は「プレビュー」から原本を表示できる。
- 画像・動画を別メモへ挿入する場合は、原本を別の添付IDへコピーし、クリック先のURLを保持する。
- 添付の動画も画像と同じ端末保存・認証付き取得を使う。保存済み原本はオフラインで利用可能。再生可能形式はブラウザによる。外部ページ・外部画像・YouTube等の外部動画は接続が必要で、URLの保存は外部コンテンツのダウンロードを意味しない。

## CRM

- ノートのツールバー「CRM」で、顧客・会社・案件などのページURLと名前を登録する。複数登録でき、「資料」で名前検索・関連先の絞り込みができる。
- `note.crmLinks` にID・種類・名前・URLを保存する。既存のノートJSON、端末保存、サーバー同期、競合検出を使用し、本文・元分類・添付を保持する。関連付けを外してもCRM側のデータは変更しない。
- この段階はURLによる関連付け。CRMの顧客・案件データの自動取得、CRM側からの関連資料表示、双方向更新は未接続。接続先のCRMとAPI・認証方式の特定後に追加する。資格情報はノートJSONへ保存しない。

## 検証と反映

- `npm test`：URL検証、CRMの保存形式、画像・動画の原本とクリック先の分離を含む。
- `npm run build`：型検査と公開UIの生成。
- GitHub Actionsの `tests/note-links.cjs`：実際のクリック、文字入力、リンクの変更・解除、画像・動画、メモ遷移、CRM検索、オフライン再読み込みを確認する。データは架空のテスト用。
- Web側の変更のみ。検証後にmainへマージし、本番サーバーでは既存の `sudo bash /var/www/canvas.uzero.style/bin/upgrade-hybrid-v2.sh` を実行する。公開 `build-version.json` とmainのコミットを照合する。本番反映と利用者の端末での確認は、ビルド・テスト成功とは別に扱う。今回の変更にはAPK再ビルドは不要。
